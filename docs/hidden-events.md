# FD2 隐藏事件格与隐藏商店

> 数据来源：`FDFIELD.DAT`、`FDSHAP.DAT`、`dseg03` 的 per-place 表（0x6238D，31 字节/项）。
>
> 本文把原先放在 `docs/game-knowledge.md` §11 的全关卡隐藏事件格独立出来，并补充隐藏商店入口。
> 章节编号按游戏流程排列：内部 state 0 记为第一章，state 1 为第二章，以此类推；因此「第二十章 死亡般的沉寂」就是通常说的死之沼泽。

## 1. 隐藏商店

### 1.1 进入方法

在城镇/地点画面的场所选单里：

1. 把光标移到表中「需停在」对应的设施（0=酒店、1=武器店、2=出口、3=道具店、4=教会）。
2. 按下表中「按键」：**Shift/Ctrl/Alt + 功能键**。
3. 该选项会变成「？？？」，再按 Enter 即可进入隐藏商店。

> 原版表存的是 BIOS 扫描码，不是字母。例如 0x67 = **Ctrl+F10**；按字母 g 会触发 BGM 切换（g 的扫描码是 0x22，城镇/地点画面的通用切歌键）。
> DOSBox-X 默认把 Ctrl+F10 用作“释放鼠标”，会截获这个组合键；要测试需改 Keymapper，或使用已修复组合键扫描码的 port 版。
> per-place 表是 1-based（访问器 0x4E809 先 `dec` 再乘 31），所以「第二章 羅德鎮」对应表的第 1 项；第一章没有这个入口。
> 隐藏商店的商品表来自每个章节条目的最后 8 字节；第二十三章–第二十五章的条目为空，故没有隐藏商店。

### 1.4 附：城镇画面的 G 键不是隐藏商店

在城镇/地点选单里按 `G`（扫描码 `0x22`）会切换 BGM：内部计数器按
0→1→…→9→0 循环，共 10 个轨道，不是随机。它不是教会专属，也不是隐藏
商店键；只要当前画面有场所选单就可能生效。隐藏商店的组合键见上表。
