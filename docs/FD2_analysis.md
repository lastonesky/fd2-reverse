## 三、通用 DAT 档案格式

**所有 .DAT 文件共享相同的容器格式**——由工具 **AFM (Animation File Manager) V1.00** (作者 Lo Yuan Tsung, 1993) 或类似工具创建。

### 3.1 头部结构

```
偏移     大小     说明
──────   ────     ──────────────────────────────────
0x00     4 bytes  魔数: 'LLLL' (0x4C4C4C4C)
0x04     2 bytes  魔数续: 'LL'   (0x4C4C)
                   → 合计 "LLLLLL" (6字节)
0x06     4 bytes  u32 LE: header_size
                   = 整个头部的总字节数
                   (含 magic + 此字段本身 + 偏移表)
0x0A     N×4      u32 LE 偏移表:
                   N = (header_size - 10) / 4
                   最后一个条目为 sentinel,
                   指向数据区末尾 (= 文件大小)
```

### 3.2 解析代码

```c
typedef struct {
    char     magic[6];       // "LLLLLL"
    uint32_t header_size;    // 头部总字节数
    uint32_t offsets[];      // 柔性数组, N = (header_size - 10) / 4
} DATHeader;

// 资源数量 = N - 1 (最后一个offset是sentinel)
// 资源 i 的数据范围: [offsets[i], offsets[i+1])
// 资源 i 的大小:      offsets[i+1] - offsets[i]
```

## 四、各资源文件的内部子格式

### 4.1 BG.DAT — 背景图片 (55 个资源)

每个资源为一张 **320×100 压缩背景图**。

```
偏移     大小     说明
──────   ────     ──────────────
0x00     u16 LE   宽度 = 0x0140 = 320
0x02     u16 LE   高度 = 0x0064 = 100
0x04     变长     压缩像素数据 (RLE 或类似)
```

- 原始未压缩 = 320×100 = 32,000 字节
- 大多数资源远小于此值，说明使用了 **RLE 行压缩**
- 少量资源大小仅 7 字节 (如索引 10-12, 14, 19, 22, 25, 38, 45, 53)，标记为 **10×3** 尺寸——可能是空白/占位图

### 4.2 FDSHAP.DAT — 精灵形状/调色板 (66 个资源)

资源以 **成对** 形式出现：**调色板 (256色)** + **精灵图**。

#### 调色板资源 (1200 或 1600 字节)
```
偏移     大小     说明
──────   ────     ──────────────
0x00     1200/1600  256色 × 3字节(RGB) 调色板
                    或 256色 × 2字节(RGB565) 调色板
```

#### 精灵图资源 (24×24 像素)
```
偏移     大小     说明
──────   ────     ──────────────
0x00     u16 LE   宽度 = 0x0018 = 24
0x02     u16 LE   高度 = 0x0018 = 24
0x04     变长     压缩像素数据 (索引色)
```

### 4.3 FDTXT.DAT — 文本数据 (34 个资源)

每个资源为一个 **文本字符串表**，使用自定义编码（可能是 Big5 码），前面带有 u16 偏移索引。

```
偏移     大小     说明
──────   ────     ──────────────
0x00     变长     u16 偏移索引表
         变长     文本字符串数据 (Big5 编码)
```

### 4.4 FDMUS.DAT — 音乐数据 (19 个资源)

每个资源为标准 **IFF/XMIDI** 格式的音乐序列。

```
偏移     大小     说明
──────   ────     ──────────────
0x00     4        "FORM" (IFF 标准)
0x04     u32 BE   FORM 数据长度
0x08     4        类型标识:
                   "XDIR" = 目录信息
                   "XMID" = XMIDI 音乐序列
```

XMIDI 数据包含子块：
- **CAT ** — 目录
- **XMID** — XMIDI 序列数据
- **TIMB** — 音色表
- **EVNT** — 事件数据

### 4.5 FDOTHER.DAT — 综合资源 (102 个资源)

包含多种不同格式的资源混合：

| 资源类型 | 标识 | 说明 |
|----------|------|------|
| **精灵图** | 首2字节 = u16 宽/高 (如 24×24) | 与 FDSHAP.DAT 相同格式 |
| **LMI1 格式** | "LMI1" 魔数 | 自定义图像/动画格式 |
| **320×200 图片** | `40 01 C8 00` (320×200) | 完屏图片，带调色板 |
| **256色调色板** | `00 00 00 03` + 768字节 | 标准 VGA 256色 RGB 调色板 |
| **嵌套 DAT** | "LLLLLL" 魔数 | 嵌套的 TITLE.DAT (完整 DAT 档案) |

#### LMI1 子格式
```
偏移     大小     说明
──────   ────     ──────────────
0x00     4        "LMI1" 魔数
0x04     u16 LE   帧数/参数
0x06     ...      帧偏移/大小索引表
         变长     压缩图像帧数据
```

### 4.6 FDFIELD.DAT — 地图/关卡数据 (98 个资源)

包含地图块定义、碰撞数据、NPC 位置等。

```
偏移     大小     说明
──────   ────     ──────────────
0x00     变长     地图瓦片数据 (u16/u32 索引)
         变长     事件/触发器数据
         变长     NPC/物体位置数据
```

### 4.7 DATO.DAT — 附加数据 (135 个资源)

所有资源均以 `0x10000000` 开头 (type = 0x10)，后面跟 u32 偏移表和数据。

```
偏移     大小     说明
──────   ────     ──────────────
0x00     u32 LE   类型 = 0x00000010
0x04     变长     内部偏移/索引表
         变长     压缩数据
```

末尾附有 768 字节的 **256 色 VGA 调色板**。

### 4.8 FIGANI.DAT — 人物动画 (407 个资源)

资源呈 **3个一组** 的模式重复：

| 序号 | 大小 | 说明 |
|------|------|------|
| N+0 | 大 (数千~数万字节) | 动画精灵图集 (NxN 尺寸, 如 11×11, 4×4, 7×7) |
| N+1 | 3 字节 (00 00 0A) | 分隔符/空帧标记 |
| N+2 | 大 | 另一组动画精灵图集 |

- 帧间隔为3，每组第一个为精灵图数据，第二个为3字节分隔符
- 精灵图尺寸多样：4×4, 6×6, 7×7, 10×10, 11×11, 15×15, 17×17 等

### 4.9 ANI.DAT — AFM 动画 (8 个资源)

每个资源为完整的 **AFM (Animation File Manager)** 动画文件。

```
偏移     大小     说明
──────   ────     ──────────────
0x00     80 bytes ASCII 版权字符串:
           "AFM - Animation File Manager Version 1.00
            Copyright (C) 1993 Lo Yuan Tsung 09/29"
0x50     1 byte   0x1A (记录分隔符)
0x51     80 bytes 标题字符串 (默认 "Empty Title.")
0xA1     u16 LE   动画参数 1 (如 0x0041 = 65)
0xA3     u16 LE   调色板大小 (如 0x0100 = 256)
0xA5     u16 LE   动画参数 2
0xA7     u16 LE   宽度 (如 0x0140 = 320)
0xA9     u16 LE   高度 (如 0x00C8 = 200)
0xAB     u16 LE   总像素数 (如 320×200 = 64000)
0xAD     ...      帧数据 (RLE 压缩)
```

### 4.10 TAI.DAT — 战斗/太极数据 (55 个资源)

包含战斗相关的图形和数据。

### 4.11 TITLE.DAT — 标题画面 (6 个资源)

嵌套在 FDOTHER.DAT 资源[6]中，也是标准 DAT 档案格式，包含标题画面图形数据。

### 4.12 FDICON.B24 — 图标精灵

```
偏移     大小     说明
──────   ────     ──────────────
0x00     u16 LE   宽度 = 0x0018 = 24
0x02     u16 LE   高度 = 0x0018 = 24
0x04     ...      24位 (B24) 像素数据 + 偏移索引
```

## 五、总结解析方法

要正确解析 FD2.EXE 的资源文件：

1. **打开 DAT 文件** → 读取6字节魔数 `"LLLLLL"`
2. **读取 header_size** (u32 LE @ offset 6)
3. **计算资源数** = `(header_size - 10) / 4 - 1`
4. **读取偏移表** → 每个资源的起止范围为 `[offsets[i], offsets[i+1])`
5. **根据文件名判断子格式**：BG→图片, SHAP→精灵, MUS→XMIDI, TXT→文本等
6. **解压资源数据** (各子格式使用不同的 RLE 变体)
